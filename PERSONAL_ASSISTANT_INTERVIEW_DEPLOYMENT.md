## 🎯 Interview Flow Phases

### Phase 1: Introduction (2 minutes)
- Name and greeting
- Current situation assessment
- Available hours per week
- **Progress**: User becomes known entity

### Phase 2: Skills Discovery (3 minutes)
- Technical skills identification
- Creative abilities assessment
- Business experience capture
- Strongest skill deep-dive
- **Progress**: Capabilities mapped

### Phase 3: Experience Deep Dive (2 minutes)
- Professional background analysis
- Career motivation understanding
- Achievement and project examples
- Learning activity assessment
- **Progress**: Experience contextualized

### Phase 4: Goals & Preferences (2 minutes)
- Income goal setting ($500 - $5,000+)
- Work type preferences
- Deal-breakers identification
- Constraint documentation
- **Progress**: Direction established

### Phase 5: Hidden Talents (1 minute)
- Hobby monetization potential
- Natural strengths recognition
- Passion project identification
- **Progress**: Complete profile built
