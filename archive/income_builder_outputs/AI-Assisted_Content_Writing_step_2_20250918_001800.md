# Step 2: Week 1: Build portfolio with 3 sample articles

Below is a clear, day-by-day action plan for Week 1 to build a professional portfolio of three sample articles as part of the AI-Assisted Content Writing opportunity. Every recommended tool and service is an internal platform capability. The plan specifies tasks, which internal agents/tools to use, time estimates, and expected outcomes.

Overview objective
- Produce three polished, publish-ready sample articles (800–1,500 words each) that demonstrate AI-assisted research, writing, editing, design, SEO, and distribution. Deliverables: three article files (HTML/Markdown), featured images, meta tags + SEO score, a landing page showcasing the portfolio pieces, and basic analytics tracking.

Day-by-day plan

Day 1 — Topic selection and briefs (3–4 hours)
1. Run keyword and audience research using ML Analytics.
   - Tool: ML Analytics (use the Topic Discovery and Audience Insights modules).
   - Action: Generate 8–10 high-opportunity topic ideas aligned to target verticals, search intent, and estimated traffic potential.
   - Expected outcome: Ranked list of candidate topics with search volume, competition score, and recommended primary/secondary keywords.
2. Choose three topics and create content briefs using the content-creation workflow.
   - Tools: content-creator agent + internal Content Brief Template (via agent API).
   - Action: For each chosen topic, produce a brief including target keywords, target persona, angle, headline options, recommended word count, internal links, and CTA.
   - Expected outcome: Three completed content briefs (one per article) stored in the project workspace and ready for drafting.

Day 2 — Drafting first drafts with AI Content Studio (4–6 hours)
1. Generate first drafts using the AI Content Studio writing model and content-creator agent.
   - Tools: AI Content Studio (writing model) + content-creator agent to orchestrate tone and structure.
   - Action: For each brief, produce an initial draft (800–1,500 words) with headings, intro, body, conclusion, suggested images, and internal linking notes.
   - Expected outcome: Three initial drafts saved as editable Markdown/HTML in the workspace. Each draft includes suggested metadata and alt-text for images.

Day 3 — Human editing and refinement (3–5 hours)
1. Use editing-agent (copy-editor) to refine tone, clarity, and correctness.
   - Tools: editing-agent + plagiarism-check module in AI Content Studio.
   - Action: Perform two rounds of edits: structural (flow, headers, accuracy) and copy edits (grammar, style, brand voice). Run a plagiarism check and fix any flagged content.
   - Expected outcome: Three edited drafts with tracked changes, comments resolved, and clean final text ready for SEO optimization.

Day 4 — SEO optimization + performance scoring (2–3 hours)
1. Optimize each article using the internal SEO tool and ML Analytics SEO module.
   - Tools: ML Analytics (SEO module) + Publishing Automation SEO checker.
   - Action: Add optimized meta titles, meta descriptions, H-tags, schema (article structured data), image alt-text, and internal linking. Ensure keyword density and readability targets are met.
   - Expected outcome: Each article achieves the platform’s SEO score target (recommendation: SEO score ≥ 80/100), and a pre-publish checklist is completed.

Day 5 — Visual design and featured images (2–4 hours)
1. Create featured images, social header images, and in-article graphics via AI Content Studio.
   - Tools: AI Content Studio (DALL·E 3 and/or Stable Diffusion) + design-agent for layout and image variations.
   - Action: Generate 2–3 image options per article (featured + social). Design a consistent visual style—branded color palette and typography—to show cohesive portfolio identity.
   - Expected outcome: Finalized images in web-optimized formats (JPEG/WebP) and image metadata saved. Branded visual style guide for the three pieces.

Day 6 — Assemble portfolio landing page and schedule publication (3–5 hours)
1. Build a simple portfolio landing page and publish articles using the Publishing Automation system.
   - Tools: publishing automation system + coding-agent (if custom layout or micro-interactions are needed).
   - Action: Create a landing page showcasing the three samples (excerpt, featured image, CTA to contact/get a demo). Publish each article as a blog post or portfolio item on the staging domain/CMS via API integration.
   - Expected outcome: Live staging page with three published posts and a portfolio landing page accessible to stakeholders. All assets are stored in the project workspace.

Day 7 — QA, analytics setup, and promotion assets (2–3 hours)
1. QA and cross-device check.
   - Tools: publishing automation (preview tool) + design-agent for final visual QA.
   - Action: Verify mobile/tablet/desktop layouts, test links, check image responsiveness, and validate structured data with the platform’s schema validator.
   - Expected outcome: No critical errors, all pages pass QA.
2. Set up analytics tracking and create short promotional copy.
   - Tools: ML Analytics (tracking setup) + marketing-agent for headlines and social copy.
   - Action: Add tracking tags, UTM templates, and set up a simple dashboard to track page views, time on page, engagement, and initial conversion events (contact clicks). Produce a suite of micro-assets: 3 social posts, 3 email snippets, and 3 social card images for distribution.
   - Expected outcome: Analytics dashboard is live; promotional assets ready for distribution.

Roles and responsibility recommendations
- Project Lead (you): coordinate agents, approve briefs and final drafts, handle client/stakeholder reviews.
- content-creator agent: initial drafting and structure control.
- editing-agent: two-pass human-style edits and quality check.
- design-agent: image generation and visual layout.
- marketing-agent: headlines, metadata, and promotional copy.
- coding-agent: landing page assembly / CMS API calls if needed.
- ML Analytics team: topic research, SEO scoring, and dashboard setup.

Deliverables by end of Week 1
- Three publish-ready articles (Markdown/HTML) optimized for SEO.
- Three branded featured images and social image variants.
- Three metadata files (meta title, meta description, keywords, schema).
- Portfolio landing page showcasing the three pieces.
- Analytics dashboard tracking key metrics (views, engagement, CTAs).
- Promotional asset pack (social copy, email snippets, social cards).
- Internal project folder with briefs, drafts, edit logs, and final assets accessible via API.

Success criteria and KPIs (initial targets)
- Each article SEO score ≥ 80 (platform SEO metric).
- Readability score within target range for audience (e.g., Grade 7–10 or per brief).
- Live portfolio page accessible and mobile-friendly.
- Analytics tracking capturing page views and engagement for each article.
- Promotional asset pack ready for distribution at launch.

Why use our internal platform tools (benefits)
- Seamless integration: content, images, SEO, publishing, and analytics are unified via internal APIs so you avoid exporting/importing between multiple external services.
- Cost savings: using integrated agents and AI Content Studio reduces recurring costs compared to third-party subscriptions (design tools, writing tools, and analytics).
- Faster workflow: orchestration via the 102+ specialized agents speeds up parallel tasks (drafting, editing, design, and deployment).
- Traceability and versioning: everything is stored in the platform workspace for audit trails, reuse, and rapid iteration.
