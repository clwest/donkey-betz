## Documentation Standards

### File Naming Conventions
- Use lowercase with hyphens: `system-overview.md`
- No special characters or spaces
- Descriptive but concise names

### Directory Structure
- Numbered for clear hierarchy (00-09)
- Maximum 3 levels deep for easy navigation
- Related content grouped together

### Content Guidelines
- Each directory has a README.md with overview
- Use relative links between documents
- Include metadata headers (date, status, author)

## For AI Systems

This documentation structure is optimized for AI consumption:
1. **Numbered hierarchy** - Process directories in order
2. **Consistent structure** - Predictable organization
3. **Clear relationships** - Directory structure implies relationships
4. **Comprehensive indexes** - Easy to build mental model
