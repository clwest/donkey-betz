🏈 Sports Betting Debug Console

📋 How to Use This Debug Tool

  1. Open your browser's Developer Console:
    • Chrome/Edge: Press Cmd+Option+J (Mac) or Ctrl+Shift+J (Windows)
    • Firefox: Press Cmd+Option+K (Mac) or Ctrl+Shift+K (Windows)
    • Safari: Enable Developer menu, then press Cmd+Option+C
  2. Navigate to your React app at http://localhost:3000
  3. Go to the Sports Betting Hub page
  4. Watch the console for detailed debug logs showing:
    • 🔍 API requests and responses
    • ✅ Successful data loads
    • ❌ Any errors or issues
    • 📊 Data counts and structure

🔍 What to Look For in Console

The debug logs are color-coded with emojis:

  • 🏁 [Dashboard] - Component lifecycle and rendering
  • 🔍 [Sports API] - API requests and responses
  • ✅ Success logs - Data successfully loaded
  • ❌ Error logs - Problems or failures
  • ⚠️ Warning logs - Missing or unexpected data
  • 🎯 Data counts - Number of items received

🎯 Expected Data Flow

  1. Component Mount: 🚀 [Dashboard] Component mounted, loading initial data...
  2. API Requests: 🔍 [Sports API] Request: GET /api/v1/sports/summary/
  3. Data Reception: ✅ [Sports API] Response: {data with counts}
  4. State Updates: ✅ [Dashboard] Data loaded: {sports types, games, etc.}
  5. Rendering: 🎨 [Dashboard] Rendering sports overview with: [array of sports]

⚠️ Common Issues to Check

  • Empty Arrays: If you see [] or length: 0, the API is returning no data
  • 404 Errors: API endpoints may be incorrect or not running
  • CORS Errors: Backend may not be configured for frontend access
  • Network Errors: Backend server may not be running on port 8000
  • Auth Errors: Token may be invalid or expired

✅ What Success Looks Like

When everything is working correctly, you should see:

  • Sports types with counts > 0
  • Live games array (may be empty if no games are live)
  • Trending games with actual game data
  • Successful rendering of sports cards
  • Games loading when you select a sport
