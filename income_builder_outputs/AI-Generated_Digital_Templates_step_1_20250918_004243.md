# Step 1: Week 1: Research trending templates on Etsy

Below is a clear, day-by-day action plan for Week 1 to research trending templates on Etsy as part of the AI-Generated Digital Templates opportunity. Every recommended tool and service is from our internal Unified Donkey Betz Platform. The plan shows specific steps, which internal tools/agents to use, and measurable expected outcomes.

Summary objective
- Produce a validated research pack that identifies the top template niches, visual styles, keywords/tags, pricing ranges, delivery formats, and competitor features on Etsy-like marketplaces, and deliver 3–5 quick prototype directions to test in Week 2.

Week 1 plan (Day 1–7)

Day 1 — Define scope and success metrics
Steps
1. Kickoff brief: Use the Agent Orchestration API to create a Week 1 research project and assign roles to internal agents: market-research-agent (collection), design-agent (visual analysis), marketing-agent (SEO/keywords), content-creator (listing style), and ML Analytics (data modeling).
2. Define research scope: target product categories (e.g., wedding invites, business card templates, social media kits, planners, resume templates), target geographies, and time window (last 6 months).
3. Set KPIs: top-10 niches by demand score, top 50 keywords, 3 prototype directions, pricing bands, competition intensity.

Internal tools to use
- Agent Orchestration API (to set tasks and deadlines)
- market-research-agent (assign data collection)
- ML Analytics (to set KPI definitions and modeling parameters)

Expected outcomes
- A formal project brief inside the platform with assigned agents, timeline, and KPIs.
- Clear acceptance criteria for the Week 1 deliverables.

Day 2 — Collect marketplace signals
Steps
1. Use market-research-agent to collect publicly available marketplace signals from Etsy via our compliant Marketplace Connector (internal data connector) and aggregated datasets the platform maintains. Data to collect: listing titles, tags, prices, sales indicators (sales counts/ratings where available), images, and product descriptions for the chosen categories.
2. Pull platform-side social signals (Pinterest/Instagram trends and search volume approximations) using the platform’s Social Trend Connector.

Internal tools to use
- market-research-agent (data collection)
- Marketplace Connector (internal, compliant Etsy data feed)
- Social Trend Connector (internal social insights)

Expected outcomes
- Raw dataset of 1,000–3,000 listings across target categories including metadata and images.
- Time-stamped dataset stored in the platform project workspace and available to ML Analytics.

Day 3 — Clean and enrich data; initial clustering
Steps
1. Have ML Analytics clean and normalize fields (title parsing, tag normalization, price standardization).
2. Enrich listings with additional computed fields: demand score (combining sales counts, recency, and reviews), competition score (number of similar listings), and visual style vectors generated by design-agent.
3. Run initial clustering to group listing types, visual styles (minimal vs ornate vs boho), and usage cases (weddings, small business, influencers).

Internal tools to use
- ML Analytics (cleaning, scoring, clustering)
- design-agent (image feature extraction and visual style vectors)
- Data Workspace (project data store)

Expected outcomes
- Cleaned, enriched dataset with demand and competition scores.
- 6–12 clusters of template types and 4–6 visual style vectors defined.

Day 4 — Quantitative trend analysis and keyword extraction
Steps
1. Use ML Analytics to identify the fastest-growing categories and compute velocity trends (which categories have the strongest upward trajectory last 3 months).
2. Marketing-agent runs linguistics and keyword extraction on titles/tags/descriptions to produce top 50 keywords, high-impression long-tail phrases, and seasonal keywords.
3. Produce pricing analysis: median, 25th/75th percentile, and recommended price bands per cluster.

Internal tools to use
- ML Analytics (trend velocity, pricing distributions)
- marketing-agent (keyword and SEO analysis)
- Data Visualization module (internal dashboard creation)

Expected outcomes
- A top-10 categories list ranked by demand velocity and opportunity score.
- Top 50 keywords and 20 seasonal/long-tail keyword phrases.
- Pricing bands for each template cluster.

Day 5 — Competitive feature and productization analysis
Steps
1. design-agent and content-creator perform qualitative reviews of top listings in each high-opportunity cluster to extract common product features (file formats included, number of variations, instructions, font licensing, mockups included).
2. Identify common product differentiators that drive conversion (editable file types, customizable color palettes, instant download packaging, bundled assets).
3. Capture best practices for listing presentation: image mockup types, number of product images, sample copy elements.

Internal tools to use
- design-agent (visual & feature analysis)
- content-creator (listing copy audit)
- Research Notes workspace (collation and highlights)

Expected outcomes
- A feature checklist per cluster (e.g., "Must include: .PSD/.AI/.SVG; 3 mockups; color palette file; instruction PDF").
- A list of 10 high-impact listing presentation best practices to implement.

Day 6 — Prototype ideation using AI Content Studio
Steps
1. Use AI Content Studio to quickly generate visual prototypes for the top 3–5 prioritized clusters. Run style prompts tied to the visual vectors identified earlier (e.g., “minimal neutral wedding invite set, 3 cards + RSVP card, gold foil mockup”).
2. design-agent refines outputs and prepares 2–3 direction variants for each prototype for later A/B testing.
3. Save prototypes and tag them with associated keywords and cluster IDs.

Internal tools to use
- AI Content Studio (DALL·E 3 + Stable Diffusion integration) for mockups and visual iterations
- design-agent (refinement and export of assets)
- Asset Library (store prototypes and meta)

Expected outcomes
- 3–5 visual prototype directions with high-quality mockups stored in the Asset Library.
- Each prototype labeled with target keywords, pricing band, and product feature checklist.

Day 7 — Consolidate findings and plan pilots for Week 2
Steps
1. Compile a Week 1 Research Report combining ML Analytics dashboards, keyword lists, cluster definitions, pricing strategies, competitor features, and the generated prototypes.
2. Use Revenue Engine to simulate revenue scenarios for each prototype cluster (e.g., price x conversion rate assumptions x traffic estimates) to prioritize 2–3 pilots for Week 2 production.
3. Use publishing automation to draft an initial listing schedule and SEO-driven description templates for the prioritized pilots, preparing assets and copy for quick launch.
4. Hold a brief internal review via the platform’s collaboration workspace to approve pilot directions.

Internal tools to use
- Data Visualization and Reporting (to compile the research report)
- Revenue Engine (pricing and revenue simulation)
- publishing automation (draft listing schedule and SEO-optimized templates)
- Agent Orchestration API (finalize Week 2 pilot assignments)

Expected outcomes
- Final Week 1 Research Report (deliverable) containing: top categories, top 50 keywords, 3–5 prototype directions, pricing bands, required feature checklist, and competitor insights.
- Revenue-simulated prioritization that selects 2–3 pilots to build and launch in Week 2.
- Pre-filled listing templates and a launch calendar in publishing automation ready for asset finalization.

Deliverables by end of Week 1
- Cleaned dataset and dashboards (ML Analytics) accessible in the project workspace.
- Top-10 opportunity list and top-50 keyword list.
- Feature checklist per cluster and listing best-practices guide.
- 3–5 prototype mockups (AI Content Studio outputs).
- Revenue simulation and prioritized pilot list.
- Drafted listing templates and an initial publishing schedule.

Success metrics and next steps
- Success metrics for Week 1: identification of at least 3 validated high-opportunity template niches, a top-50 keyword list, 3 prototype directions, and a prioritized pilot list with projected revenue scenarios.
- Week 2 immediate actions: finalize prototypes into production-ready templates, prepare file packages, complete listings using publishing automation, and launch pilot listings while tracking performance via ML Analytics.

Why use our internal platform (benefits)
- We avoid external tooling fees and integration complexity by using the platform’s Marketplace Connector, ML Analytics, and AI Content Studio that are already integrated with our Agent Orchestration API.
- The Revenue Engine and publishing automation allow seamless transition from research to pricing, listing, and launch with consistent data flow and fewer manual handoffs.
- Using internal agents (design-agent, marketing-agent, content-creator) reduces time-to-market and provides cohesive outputs aligned to our platform standards.
