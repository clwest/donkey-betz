# Step 3: Week 2: Design in Canva (free version)

Below is a clear, actionable Week 2 action plan that replaces “Design in Canva (free version)” with our internal platform tools while preserving Canva compatibility if you need to provide assets users can open/import in Canva free. The plan gives specific steps, the internal tools to use, time estimates, expected outcomes, QA checkpoints, and next-step handoffs for Week 3.

Goal
- Produce a complete set of AI‑Generated Digital Templates (design files, preview assets, and user-ready Canva‑importable exports) using our internal AI Content Studio and agent network. Deliver high‑quality templates ready for listing, testing, and customer customization.

Primary internal tools & services to use
- AI Content Studio (DALL·E 3 + Stable Diffusion) — generate visuals, backgrounds, icons, and hero images.
- design-agent — produce layout variants, template systems, and final editable source files (SVG, layered PNG, PDF).
- content-creator — craft template copy, on‑page instructions, template labels, and example text.
- process_media — resize, compress, and batch export assets into required formats (SVG, transparent PNG, high‑res PDF, JPG).
- create_videos — make short animated previews / GIFs for product listings (optional).
- publishing automation — schedule product pages, social posts, and email announcements once assets are final.
- Revenue Engine — configure pricing, packages, and product delivery metadata in preparation for launch.
- ML Analytics — set up tracking and A/B test parameters for preview images and template thumbnails.
- Agent collaboration API — use to coordinate handoffs and reviews among design-agent, content-creator, and QA agents.

High-level deliverables for Week 2
- 6–12 finished template files across 3 core categories (suggested: Social Post, Lead Magnet/One-page PDF, Planner Page).
- Editable source files: SVG (icons/logos), layered PNGs, and editable PDF templates.
- Canva‑importable export files: high‑res PNGs and PDFs with clear layer naming + a short import guide for Canva free users.
- 3 preview images per template + 1 animated preview (MP4/GIF) for listing.
- Template instruction text and a short “How to import into Canva Free” guide.
- QA checklist and final approval notes ready for Week 3 launch prep.

Week 2 schedule (5 working days) — timeline and steps

Day 1 — Strategy & Design Brief (2–3 hours)
1. Run kickoff with design-agent and content-creator via agent collaboration API to confirm template types, target audience, brand constraints, and palette.
   - Output: Design Brief doc (template categories, sizes, color palette, typography suggestions).
2. Use AI Content Studio to generate moodboards and visual inspiration (5–8 concept images per template type).
   - Expected outcome: 3 moodboards (one per category) for review.

Day 1–2 — Core Layouts & Component Library (6–8 hours)
3. design-agent creates 2–3 layout variations per template type using the brief and moodboards.
   - Output: Editable layout files (SVG and layered PSD-equivalent in our system).
4. Build a component library (headers, footers, icons, buttons, placeholder images, texture overlays) using AI Content Studio for unique artwork and design-agent to vectorize where needed.
   - Output: A shared asset library (SVG icons, PNG assets) stored in the platform project.

Day 2–3 — Template Assembly & Copy (8–10 hours)
5. Assemble templates: apply layouts + components + real example copy generated by content-creator.
   - For each template: produce 2 style variations (e.g., bright/minimal, photo-based/elegant).
   - Output: 6–12 assembled editable templates.
6. content-creator writes sample text, template labels, and a short “How to edit” guide per template.
   - Output: Editable text files and in-template instruction layers.

Day 3 — Internal Review & Iteration (3–4 hours)
7. Run internal design QA with design-agent and QA agent:
   - Check spacing, hierarchy, typographic scale, color contrast, and mobile readability.
   - Verify exported layer names and editability.
   - Output: QA report with change list.
8. Iterate on templates per QA feedback using design-agent.

Day 4 — Export, Canva Compatibility & Preview Assets (6 hours)
9. Using process_media, export final templates in:
   - Editable source formats (SVG, layered PSD-equivalent, editable PDF).
   - Canva-importable formats: high-res PNGs (transparent backgrounds where needed), single-page PDFs (with crop marks removed), and a set of separate asset PNGs for user reassembly in Canva free.
   - Expected outcome: ZIP package for each template with source + Canva imports + instructions.
10. create_videos produces 5–10s animated previews/GIFs showing customization (text swap, color change) for each template.
    - Output: MP4 and GIF versions sized for marketplace thumbnails and social sharing.

Day 5 — Product Packaging, Analytics Setup & Handoff (4–6 hours)
11. Work with Revenue Engine to set preliminary pricing tiers, product SKU metadata, and bundle options (single template, 3-pack, bundle).
    - Output: Draft product entries ready for final images and descriptions.
12. Use ML Analytics to set up A/B tests for 2 different preview images/thumbnails per template and install tracking hooks for engagement.
    - Output: Analytics plan and tracking tags in place.
13. publishing automation: Prepare scheduled posts and email content drafts using generated preview assets for Week 3 launch.
    - Output: Draft schedule and preview content ready for final approval.
14. Final handoff to Week 3: upload all deliverables to the project workspace, share QA report, pricing drafts, analytics plan, and “How to import into Canva Free” guide.

Quality control & checkpoints
- Design review checkpoint after initial layouts (Day 2): approve 1 variation per template before mass assembly.
- QA pass requirement: accessibility contrast > WCAG AA where applicable, fonts embedded in PDFs, and SVGs with editable text where possible.
- Export verification: open each exported PDF/PNG in a canary test environment (our process_media viewer) and run an automated import simulation into Canva-compatible format to ensure assets are reusable.
- Final sign-off from product owner before packaging (end of Day 4).

How we handle “Canva free version” requirements
- We do not use Canva internally; instead we:
  - Export templates into formats that Canva Free accepts: high-res PNGs, flattened PDFs, and grouped SVGs.
  - Provide a short step‑by‑step “How to import & edit in Canva Free” guide that shows how customers can recompose assets and edit text placeholders.
  - Include a one-click ZIP containing all necessary PNGs and PDFs so customers who only have Canva Free can customize the look without loss of quality.
- Benefit: full design control, better export fidelity, and lower cost while still serving customers who prefer Canva.

- All templates, assets, and metadata remain centralized for easier updates and iterative improvements.
