## Executive Summary

ChatGPT reviewed a podcast generated by our system and identified three categories of improvements:

1. **Content Quality** - Add concrete stories, fix shaky citations, add Analyst voice
2. **Memory Safety** - Podcast artifacts trigger poison-risk detection; need proper classification
3. **Product Opportunity** - Turn podcast generation into a sellable mini-workflow

This document provides detailed implementation plans for all three areas.

## Background: The Problem

### Current Podcast Output Issues

When the PodcastCoordinatorAgent generates debate episodes, the output has several issues:

| Issue | Example | Impact |
|-------|---------|--------|
| **Abstract claims** | "Agents are transforming work" | No concrete evidence |
| **Shaky citations** | "Kaggle article says..." | Weak credibility |
| **Self-promotional** | "I'm fired up about this!" | Embedding poison |
| **Meta-commentary** | "Suggested quick answer..." | Not broadcast-ready |
| **Missing voice** | Paul (Analyst) not used | No data grounding |
| **Date landmines** | "As of January 2026..." | Unverified claims |

### Memory Safety Concern

These traits would be flagged by `_detect_poison_risk()`:

```python
# Current podcast output would score:
poison_risk_score = 0.60  # HIGH RISK
poison_risk_factors = [
    'self_promotional',   # +0.25 - "I'm fired up..."
    'highly_abstract',    # +0.20 - no concrete metrics
    'lacks_context',      # +0.15 - meta-text mixed in
]
```

**Result:** Podcast content could pollute embeddings if stored as `approved`.

## Improvement 3: Post-Processing for Memory Promotion

### 3.1 The Problem

Raw podcast output contains:
- Meta-commentary ("Suggested quick answer...")
- Placeholder text ("Insert specific example here")
- Unverified date claims ("As of January 2026...")
- Abstract filler ("This is really important because...")

This should be stripped before promoting to `approved`.

### 3.2 Post-Processing Pipeline

**New Service:** `PodcastPostProcessor`

```python
# core/services/podcast_post_processor.py

class PodcastPostProcessor:
    """
    Session 768: Clean podcast scripts before memory promotion.

    Strips meta-commentary, verifies claims, and produces broadcast-ready text.
    """

    # Patterns to remove
    META_PATTERNS = [
        r'\[.*?\]',  # [bracketed instructions]
        r'\(suggested.*?\)',  # (suggested quick answer)
        r'Note:.*?\.', # Note: this is meta...
        r'TODO:.*',  # TODO items
        r'INSERT.*?HERE',  # INSERT EXAMPLE HERE
    ]

    # Patterns to flag for review
    DATE_PATTERNS = [
        r'As of \w+ \d{4}',  # As of January 2026
        r'In \d{4}',  # In 2026
        r'Recently',  # Vague timing
        r'This year',  # Unverified
    ]

    # Self-promotional patterns (from Memory Safety)
    PROMO_PATTERNS = [
        r"I'm fired up",
        r"I'm excited",
        r"This is huge",
        r"Game-changer",
    ]

    def process(self, script: str, context: dict = None) -> dict:
        """
        Process a podcast script for memory promotion.

        Returns:
            {
                'cleaned_script': str,
                'removed_items': list,
                'flagged_items': list,
                'promotion_ready': bool,
                'issues': list
            }
        """
        cleaned = script
        removed = []
        flagged = []
        issues = []

        # Step 1: Remove meta-commentary
        for pattern in self.META_PATTERNS:
            matches = re.findall(pattern, cleaned, re.IGNORECASE)
            removed.extend(matches)
            cleaned = re.sub(pattern, '', cleaned, flags=re.IGNORECASE)

        # Step 2: Flag date claims
        for pattern in self.DATE_PATTERNS:
            matches = re.findall(pattern, cleaned, re.IGNORECASE)
            for match in matches:
                flagged.append({
                    'type': 'unverified_date',
                    'text': match,
                    'action': 'verify_or_remove'
                })

        # Step 3: Flag promotional language
        for pattern in self.PROMO_PATTERNS:
            if re.search(pattern, cleaned, re.IGNORECASE):
                flagged.append({
                    'type': 'promotional_language',
                    'text': pattern,
                    'action': 'tone_down'
                })

        # Step 4: Check for concrete evidence
        has_numbers = bool(re.search(r'\d+%|\$\d+|\d+ (hours|days|minutes)', cleaned))
        has_story = bool(re.search(r'(example|case|when|story)', cleaned, re.IGNORECASE))

        if not has_numbers:
            issues.append('No concrete metrics found')
        if not has_story:
            issues.append('No concrete story/example found')

        # Step 5: Determine promotion readiness
        promotion_ready = (
            len(flagged) == 0 and
            len(issues) == 0 and
            len(cleaned.strip()) > 100
        )

        return {
            'cleaned_script': cleaned.strip(),
            'removed_items': removed,
            'flagged_items': flagged,
            'promotion_ready': promotion_ready,
            'issues': issues
        }

    def promote_to_approved(self, memory_id: str) -> bool:
        """
        Promote a memory from exploratory to approved after processing.
        """
        from core.models_unified_system import AgentMemory

        memory = AgentMemory.objects.get(id=memory_id)

        # Process the content
        result = self.process(memory.content)

        if not result['promotion_ready']:
            logger.warning(f"Memory {memory_id} not ready for promotion: {result['issues']}")
            return False

        # Update the memory
        memory.content = result['cleaned_script']
        memory.safety_class = 'approved'
        memory.save(update_fields=['content', 'safety_class'])

        # Trigger embedding generation
        from core.tasks import generate_memory_embedding
        generate_memory_embedding.delay(str(memory.id))

        return True
```

### 3.3 Integration with Workflow

The post-processor integrates at step 9-10 of the workflow:

```python
# In workflow execution
if step_id == '9_quality_gate':
    processor = PodcastPostProcessor()
    result = processor.process(full_script)

    if result['flagged_items']:
        # Return to human for review
        return HumanAttentionItem.create(
            item_type='review',
            title=f"Podcast script needs review: {len(result['flagged_items'])} issues",
            payload={
                'script': full_script,
                'flagged': result['flagged_items'],
                'issues': result['issues']
            }
        )

    if result['promotion_ready']:
        # Auto-promote
        processor.promote_to_approved(memory_id)
```
