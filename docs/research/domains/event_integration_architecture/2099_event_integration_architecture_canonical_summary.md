### 3.4 Canonical + mirror invariants (S2003 §10.3.1 canonical)

For every Class-1 governance event, the canonical + mirror pattern requires:

1. **`event_id` equality** — both writes carry the same UUID envelope field.
2. **`mirror_of` tag on the mirror substrate** — the mirror payload includes `mirror_of='eventbus:HAI_*'` (or equivalent) to declare the canonical.
3. **Emission ordering** — canonical FIRST via `EventBus.publish` + mirror via `transaction.on_commit` hook (ensures the mirror only lands if the canonical did).
4. **Shared wrapper mandate** — all emissions via `publish_hai_*_event` / `publish_authority_*_event` per S2002 §6.2. Direct `EventBus.publish(...)` bypass without the mirror write is a defect.
5. **Version-bump rules** — Adding a mirror = minor bump; removing = minor bump; changing canonical substrate = major bump per S1275 §7.5.

**Status at HEAD `b9b73ed0`:** The invariants are **unenforced** per S2004 §14.3.4 verifier grep — zero `mirror_of` tag matches; zero implemented Class-1 canonical + mirror pairs.
