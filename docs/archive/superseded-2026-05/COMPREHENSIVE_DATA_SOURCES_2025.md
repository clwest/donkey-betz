## TECHNICAL NOTES

### Rate Limits (Common Patterns)
- **Free RSS:** Usually unlimited (respect robots.txt)
- **Free APIs (no key):** Often rate-limited by IP (100-1000/day)
- **Free APIs (with key):** 25-1000 calls/day typically
- **Paid tiers:** Start at $10-100/month for higher limits

### Data Freshness
- **Real-time:** News, weather, sports scores
- **Hourly:** Stock prices, crypto, job boards
- **Daily:** Most RSS feeds, academic journals
- **Weekly/Monthly:** Government data, research

### Authentication Types
1. **None:** Open RSS, some government APIs
2. **API Key:** Header or query param
3. **OAuth 2.0:** Social media platforms
4. **Custom tokens:** Some enterprise APIs

### Best Practices
1. **Start with RSS:** Easiest to implement, no auth
2. **Cache aggressively:** Respect rate limits
3. **Use ETags/Last-Modified:** Avoid redundant fetches
4. **Implement exponential backoff:** Handle rate limits gracefully
5. **Monitor API deprecations:** Subscribe to developer newsletters
