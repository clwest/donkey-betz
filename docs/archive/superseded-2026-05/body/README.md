# Body Systems Documentation

The AI platform uses a biological metaphor with 9 body systems for monitoring and organization.

## Systems

| System | Purpose | Service File |
|--------|---------|--------------|
| **HEART** | Central health monitoring | `core/services/heart.py` |
| **LUNGS** | Resource & capacity management | `core/services/lungs.py` |
| **CIRCULATORY** | Data flow monitoring | `core/services/circulatory.py` |
| **SPINE** | Central API routing | `core/services/spine.py` |
| **IMMUNE** | Security & threat detection | `core/services/immune.py` |
| **DIGESTIVE** | Data ingestion & processing | `core/services/digestive.py` |
| **MUSCULAR** | Agent work execution | `core/services/muscular.py` |
| **BRAIN** | Cognitive processing | `core/services/brain.py` |
| **SKIN** | Workspace output monitoring | `core/services/skin.py` |

## Files in this folder

- `BODY_ARCHITECTURE.md` - Overall architecture design
- `BODY_SYSTEMS_REFERENCE.md` - Complete reference for all systems
- `BODY_IMPLEMENTATION_ROADMAP.md` - Implementation history
- `BODY_INTEGRATION_GAPS.md` - Known gaps and future work
