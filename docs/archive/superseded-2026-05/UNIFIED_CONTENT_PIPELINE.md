## DATABASE MODELS

### ContentPackage
```python
class ContentPackage(models.Model):
    """A complete content package ready for sale/delivery"""
    id = UUIDField(primary_key=True)

    # Basic Info
    name = CharField(max_length=200)
    description = TextField()
    tier = CharField(choices=TIER_CHOICES)  # quick, ad, brand, series, pitch, production
    category = CharField(max_length=100)    # restaurant, healthcare, education, etc.

    # Pricing
    base_price = DecimalField()
    discount_percent = IntegerField(default=0)

    # Status
    status = CharField(choices=STATUS_CHOICES)  # generating, ready, sold, delivered
    is_public = BooleanField(default=True)      # In marketplace or private

    # Generation Config
    prompt = TextField()                    # Original creation prompt
    generation_config = JSONField()         # All settings used

    # Assets (stored as JSON with file references)
    assets = JSONField()
    # {
    #   "images": [{"id": "...", "type": "mascot", "url": "..."}],
    #   "videos": [{"id": "...", "duration": 30, "url": "..."}],
    #   "audio": [{"id": "...", "voice_id": "...", "url": "..."}],
    #   "documents": [{"id": "...", "type": "script", "url": "..."}]
    # }

    # Preview assets (for marketplace display)
    preview_image = URLField()
    preview_video = URLField()
    preview_audio = URLField()

    # Stats
    views = IntegerField(default=0)
    purchases = IntegerField(default=0)

    # Ownership
    created_by = ForeignKey(User)           # Who generated it
    purchased_by = ForeignKey(User, null=True)  # Who bought it (if sold)

    # Timestamps
    created_at = DateTimeField(auto_now_add=True)
    purchased_at = DateTimeField(null=True)
    delivered_at = DateTimeField(null=True)
```

### ContentAsset
```python
class ContentAsset(models.Model):
    """Individual asset within a package"""
    id = UUIDField(primary_key=True)
    package = ForeignKey(ContentPackage)

    asset_type = CharField(choices=ASSET_TYPES)
    # image, video, audio, document, source_file

    name = CharField(max_length=200)
    file_url = URLField()
    file_size = IntegerField()

    # Type-specific metadata
    metadata = JSONField()
    # For images: width, height, format
    # For videos: duration, resolution, fps
    # For audio: duration, sample_rate, format

    created_at = DateTimeField(auto_now_add=True)
```

### ContentPurchase
```python
class ContentPurchase(models.Model):
    """Record of a content package purchase"""
    id = UUIDField(primary_key=True)

    package = ForeignKey(ContentPackage)
    buyer = ForeignKey(User)

    # Pricing at time of purchase
    price_paid = DecimalField()
    discount_applied = IntegerField()

    # Customizations requested
    customizations = JSONField(null=True)

    # Delivery
    discord_channel_id = CharField(max_length=100, null=True)
    delivered = BooleanField(default=False)
    delivered_at = DateTimeField(null=True)

    # Payment
    stripe_payment_id = CharField(max_length=100, null=True)
    payment_status = CharField(choices=PAYMENT_STATUS)

    created_at = DateTimeField(auto_now_add=True)
```

## DISCORD COMMANDS

### /create - The Main Generator
```
/create <tier> <prompt> [options]

Tiers:
- quick     ($5-29)    - Birthday messages, simple content
- ad        ($29-99)   - Small business ads
- brand     ($99-499)  - Full brand packages
- series    ($499-2999) - Content series
- pitch     ($2999-9999) - Series/movie pitches
- production ($9999+)   - Full productions

Options:
- voice: Choose from marketplace or generate new
- style: Animation style preference
- rush: Priority generation (2x price)
- private: Don't list in marketplace
```

### /browse - Marketplace Browser
```
/browse [category] [filters]

Categories: mascots, ads, brands, series, pitches
Filters: price_max, industry, style
```

### /buy - Purchase Package
```
/buy <package_id> [customizations]

Customizations: name changes, color tweaks, voice swap
```

### /my-content - View Purchases
```
/my-content [filter]

Shows all purchased and generated content
```
