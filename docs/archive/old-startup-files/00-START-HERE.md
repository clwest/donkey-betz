## 🛠️ Maintenance

### Where New Documents Go

**Session completion report:**
→ `session-reports/YYYY-MM-DD/session-N-description.md`

**Handoff to next Claude:**
→ `handoffs/session-N-handoff.md`

**Strategic plan or roadmap:**
→ `plans/plan-name.md`

**Status snapshot:**
→ `status/current/` (move old to `historical/` when outdated)

**Feature completion:**
→ `completions/feature-name-complete.md`

**Bug fix:**
→ `fixes/completion-reports/fix-name.md`

**System audit:**
→ `audits/audit-name.md`

**User guide:**
→ `guides/user-guides/guide-name.md`

**Development guide:**
→ `guides/development/guide-name.md`

**Priority update:**
→ `priorities/current/next-session-task.md` (replace existing)

### Archive Rules

**Archive when:**
- Document is >30 days old AND
- No longer referenced in active work AND
- Superseded by newer version

**How to archive:**
1. Move to `archive/YYYY-MM/`
2. Add note in directory README
3. Keep link in this index with (ARCHIVED) tag
