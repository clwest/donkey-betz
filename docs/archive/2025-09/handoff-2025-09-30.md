## 🆘 Troubleshooting Reference

### UI Shows Spinner Forever
**Cause**: WebSocket not connecting or no data
**Fix**:
1. Check `core/routing.py:282` uses `IncomeBuilderConsumer`
2. Verify import: `from intelligence.consumers import IncomeBuilderConsumer`
3. Restart server: `pkill -f runserver && python manage.py runserver 8000`
4. Check database has opportunities: `OpportunityTracking.objects.count()`

### No Opportunities in Database
**Cause**: Database empty or opportunities for wrong user
**Fix**:
```bash
python scripts/populate_real_spider_data.py
```

### Server Won't Start
**Cause**: Port 8000 in use or import errors
**Fix**:
```bash
# Kill existing processes
pkill -f "python manage.py runserver"
lsof -ti:8000 | xargs kill -9

# Start fresh
python manage.py runserver 8000
```

### Spiders Return No Data
**Cause**: API rate limits or network issues
**Fix**:
- Wait 1 minute and try again
- Check internet connection
- Verify APIs haven't changed endpoints
- Look for errors in `test_real_spiders.py` output
