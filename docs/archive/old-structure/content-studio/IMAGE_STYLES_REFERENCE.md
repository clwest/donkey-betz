## Style Combination Tips

You can enhance styles by combining them in your prompt:

```python
# Example: Cyberpunk + Watercolor fusion
prompt = "A futuristic city"
style = "cyberpunk"
# The system will apply: "A futuristic city, cyberpunk style, neon lights,
# futuristic city, blade runner 2049, high tech low life"

# You can also manually combine:
prompt = "A cyberpunk city in watercolor style"
style = "watercolor"
```

## Implementation Details

**File Location**: `content/image_generation.py`

**Function**: `_apply_style_to_prompt(prompt: str, style: str) -> str`

**How it works**:
- Takes your base prompt
- Applies style-specific enhancements optimized for Stable Diffusion
- Returns enhanced prompt for better results

**Example**:
```python
# Input
prompt = "A cat"
style = "cyberpunk"

# Output (enhanced prompt)
"A cat, cyberpunk style, neon lights, futuristic city,
blade runner 2049, high tech low life"
```
