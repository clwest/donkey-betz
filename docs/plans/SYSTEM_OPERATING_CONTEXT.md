2. CORE AUTONOMOUS PATTERN (THE GOLD STANDARD)

Every fully-realized intelligence cluster follows this pattern:

A. MULTI-AGENT GROUP (NOT SINGLE AGENT)

Each domain has 5–7 cooperating agents, typically:
	•	Coordinator / Orchestrator
	•	Primary Analyst
	•	Risk / Adversarial Analyst
	•	Validation Agent
	•	Narrative / Report Agent
	•	(Optional) Advisor Proxy Agent

📌 Stock Audit Group & Blockchain Audit Group already implement this.

⸻

B. CONTINUOUS DATA FEED (SPIDERS)

Each group is fed by multiple spiders, not one source.

Spiders:
	•	Collect data continuously
	•	Normalize it
	•	Push it into agent-queryable memory
	•	Are validated for freshness & quality

⸻

C. SCHEDULED + EVENT-DRIVEN EXECUTION

Agents run via:
	•	Celery schedules (every 15–30 min)
	•	Event listeners (blockchain events, market events)
	•	Manual triggers
	•	Autonomous loops

⸻

D. CROSS-AGENT ARGUMENTATION

Agents:
	•	Challenge findings
	•	Flag anomalies
	•	Escalate risk levels
	•	Trigger advisor consultation when confidence is low or risk is high

This is not optional.

⸻

E. OUTPUT WITH CONSEQUENCES

Every group must:
	•	Produce structured outputs
	•	Log reasoning
	•	Feed learning bridges
	•	Attribute downstream value (alerts, revenue, decisions)
