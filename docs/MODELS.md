# Database Models Reference

**Last Updated:** Session 652 (December 31, 2025) - Podcast & Campaign models now have data
**Total Models:** 349 across 37 categories
**Database:** PostgreSQL with pgvector extension

## Overview

The platform uses Django ORM with PostgreSQL as the primary database. Models are organized across multiple files by domain, with the main unified system file containing the majority of models.

## Database Schema Notes

### Common Patterns

1. **UUID Primary Keys**: Most models use UUID for primary keys
2. **Timestamps**: `created_at` and `updated_at` on all models via UnifiedBaseModel
3. **Soft Deletes**: Some models use `is_active` or `deleted_at` for soft deletes
4. **JSON Fields**: Extensive use of JSONField for flexible data storage
5. **Array Fields**: PostgreSQL ArrayField for list data

### Relationships

- **User-centric**: Most models relate back to User
- **Agent-centric**: Many models relate to Agent for AI tracking
- **Project-centric**: Content models often relate to projects

### Indexes

Key indexes for performance:
- `user_id` + `created_at` (user activity queries)
- `agent_id` + `created_at` (agent activity queries)
- `embedding_vector` using pgvector (similarity search)
