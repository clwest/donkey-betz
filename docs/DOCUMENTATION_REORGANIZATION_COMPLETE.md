## 🎨 Naming Conventions Established

### Files
- Use kebab-case: `session-1-assessment.md`
- Include dates when relevant: `morning-report-2025-10-02.md`
- Be descriptive: `spider-recovery-10-session-plan.md`
- No spaces, lowercase (except README.md)

### Directories
- Use kebab-case: `session-reports/`
- Plural for collections: `guides/`, `audits/`
- Clear purpose: `completions/` not `complete/`

## 📋 Maintenance Rules

### Where New Documents Go

| Type | Location |
|------|----------|
| Session completion report | `session-reports/YYYY-MM-DD/session-N-description.md` |
| Handoff to future Claude | `handoffs/session-N-handoff.md` |
| Strategic plan | `plans/plan-name.md` |
| Status snapshot | `status/current/` (move old to historical/) |
| Completion summary | `completions/feature-name-complete.md` |
| Bug fix | `fixes/completion-reports/fix-name.md` |
| Audit | `audits/audit-name.md` |
| User guide | `guides/user-guides/guide-name.md` |
| Dev guide | `guides/development/guide-name.md` |
| Priority update | `priorities/current/next-session-task.md` (replace) |

### Archive Rules

**Archive when:**
- Document is >30 days old AND
- No longer referenced in active work AND
- Superseded by newer version

**How to archive:**
1. Move to `archive/YYYY-MM/`
2. Add note in README
3. Keep in index with (ARCHIVED) tag
