## 💡 User Workflow (Now Documented)

### Creating & Training a Character:

1. **Generate Training Set:**
   ```
   "Create a [style] [subject] character named [name]"
   ```

2. **Review Images:**
   - AI generates 6 training images
   - Shows preview grid with all images

3. **Edit if Needed (Optional):**
   ```
   "Make the ears bigger on image 3"
   "Change background to white on all images"
   ```

4. **Approve Training:**
   ```
   "These look perfect, train it!"
   ```

5. **One-Time Setup (if model doesn't exist):**
   - Go to https://replicate.com/create
   - Owner: clwest
   - Name: character-name (lowercase)
   - Visibility: Private
   - Type: Push a custom model
   - Hardware: CPU

6. **Wait for Training:**
   - Takes 30-60 minutes
   - Check status at https://replicate.com/trainings

7. **Generate with Trained Character:**
   ```
   "Generate an image of [TRIGGER_WORD] [doing something]"
   ```
