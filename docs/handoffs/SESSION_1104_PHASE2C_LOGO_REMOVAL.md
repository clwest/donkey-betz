# Session 1104 — Phase 2C (donkey-logo.png removal)

### Earlier false positive (cleared)

The Phase 2 grep using pattern `donkey-logo|donkey_logo|images/donkey` matched a few `staticfiles/js/push-service-worker.*.js` bundles. Those were caught by the broad `images/donkey` alternative — the actual references were to `images/donkey-icon.png` and `images/donkey-badge.png` (used by the push notification source at `ai_core/static/js/push-service-worker.js`, lines 25/26/41/42). **Nothing in tree references `donkey-logo` specifically.**

## Why This Matters

`context-kit hotpath` flagged `core/static/images/donkey-logo.png` (24 MB) as the single largest tracked file in the repository. Removing it:

- Cuts ~24 MB off every `git clone`.
- Reduces noise in repository inspection tools (`context-kit inspect`, `du`).
- Eliminates a tracked asset that was preserved by inertia, not by need.

Combined with prior Phase 1/2B/2C-prep work, the repo now: (a) has zero `CONFLICT` findings at the verifier, (b) treats `docs/INDEX.md` as contractually auto-generated, and (c) no longer carries its single largest dead asset.
