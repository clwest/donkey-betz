# Session 866: Research Report Improvements + Internal Data Registry

**Date:** January 29, 2026
**Focus:** ChatGPT Feedback Implementation - 3 Research Report Fixes + Internal Data Registry

## Summary

Implemented ChatGPT's feedback on improving research reports generated by the autonomous action executor. Three key fixes plus a Decision Gate feature. Also added an Internal Data Source Registry to teach agents about available DonkeyBetz data.

## Changes Made

### 1. Deliverables Section Mismatch (Fix #1)
**File:** `core/services/autonomous_action_executor.py`

**Problem:** Research reports showed "Deliverables Requested" header followed by "None specified" when no deliverables existed - a semantic mismatch.

**Solution:** Only display the Deliverables section when deliverables actually exist:
```python
# Before
## Deliverables Requested
{deliverables if deliverables else 'None specified'}

# After - only shown when deliverables exist
if deliverables:
    deliverables_section = f"""
## Deliverables Requested
{chr(10).join(f'- {d}' for d in deliverables)}
"""
```

### 2. Self-Unblocking Pattern (Fix #2)
**File:** `core/services/autonomous_action_executor.py`

**Problem:** When research returned insufficient data, the pipeline would stop without attempting to gather more data.

**Solution:** Added `_trigger_self_unblock()` method that automatically triggers data collection when research fails or returns insufficient findings:
```python
def _trigger_self_unblock(self, topic, missing_data_type):
    # Spawn spider for external data
    # OR trigger unified search refresh for internal data
    # Returns unblock result for tracking
```

**Trigger conditions:**
- `research_successful` is False
- `findings` is empty or < 50 characters

### 3. System Bindings Map (Fix #3)
**File:** `core/services/autonomous_action_executor.py`

**Problem:** Research reports referenced generic database systems (BigQuery, Snowflake) instead of actual DonkeyBetz tables.

**Solution:** Enhanced `_extract_system_bindings()` to map external references to internal models:
```python
EXTERNAL_TO_INTERNAL_MAP = {
    'bigquery': 'Use: SpiderData, BusinessResearchResult (direct Django ORM)',
    'snowflake': 'Use: SpiderData, ContentMetrics (direct Django ORM)',
    'experiment data': 'ExperimentExecution model (status, halt_reason, metrics)',
    'failed': 'Filter by status="failed" or success=False',
    # ... 25+ mappings
}
```

### 4. Decision Gate (New Feature)
**File:** `core/services/autonomous_action_executor.py`

**Addition:** Every research report now includes a Decision Gate section with:
- Data availability status
- Recommended next actions (numbered list)
- Ownership assignment
- Status indicator

Example output:
```markdown
## Decision Gate

### Data Status
✅ Data Available

### Recommended Actions
1. ✅ Synthesize 3 requested deliverable(s)
2. 📊 Review findings and validate key insights
3. 🎯 Route to appropriate agent for content creation
4. 👤 Assign to ResearchAgent for follow-up

### Ownership
**Primary Owner:** ResearchAgent
**Status:** Pending Review
```

### 5. Internal Data Source Registry (NEW)
**File:** `core/services/internal_data_registry.py`

**Problem:** Agents asked for "BigQuery access" or "CSV exports" when the data exists in our own database.

**Solution:** Created a comprehensive registry of 18 internal data sources:

| Source Key | Model | Purpose |
|------------|-------|---------|
| `experiments` | ExperimentExecution | A/B tests, feature flags, halted experiments |
| `agent_executions` | AgentExecution | Agent task logs with timing/errors |
| `research_briefs` | SelfBlog | Auto-generated research reports |
| `content_blogs` | SelfBlog | Blog posts and content |
| `deliverables` | Deliverable | Formal project deliverables |
| `spider_data` | SpiderData | Data from 77 spiders |
| `business_research` | BusinessResearchResult | Market/competitor analysis |
| `initiatives` | Initiative | 5-stage project pipeline |
| `conceptforge_runs` | ConceptForgeRun | Think tank pipeline runs |
| `agent_learnings` | AgentLearning | What agents have learned |
| `decision_records` | DecisionRecord | Autonomous decisions |
| `tool_call_records` | ToolCallRecord | Tool invocations |
| `conversations` | Conversation | User conversations |
| `user_profiles` | ExtendedUserProfile | User skills/preferences |
| `workspace_operations` | WorkspaceOperation | File operations |
| `podcast_episodes` | PodcastEpisode | Podcast content |

**Key Functions:**
```python
from core.services.internal_data_registry import (
    get_internal_data_registry,      # Get all sources
    get_data_source_for_topic,       # Find relevant sources for a topic
    build_agent_data_context,        # Build context string for prompts
    get_experiment_diagnostic_sources  # Specific experiment queries
)
```

**Example Usage:**
```python
# Find sources for "failed experiments"
sources = get_data_source_for_topic("failed experiments halted")
# Returns: [{'name': 'Experiment Executions', 'relevance': 'high'}, ...]

# Build agent context
context = build_agent_data_context("analyze failed experiments")
# Returns: Formatted markdown with models, queries, and fields
```

### 6. Research Task Enhancement
