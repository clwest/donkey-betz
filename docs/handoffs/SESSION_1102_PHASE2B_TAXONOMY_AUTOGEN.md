## `.rag/` Investigation Outcome (deferred work, recorded for the next session)

### Production reality

- `core/rag.py:top_k()` and `core/rag.py:build_docs_context()` are consumed by exactly two callers, both routing to local Ollama:
  - [`core/ask_with_docs.py`](../../core/ask_with_docs.py)
  - [`core/management/commands/askdocs.py`](../../core/management/commands/askdocs.py)
- **Production PA RAG does not use `core/rag.py`.** It uses the `Document` model + pgvector embeddings, populated by [`core/management/commands/sync_docs_index_to_documents.py`](../../core/management/commands/sync_docs_index_to_documents.py) via OpenAI embeddings (`--embed`).
- The 20 other files matching `top_k` in the repo are unrelated namespaces (`unified_pa_entrypoint`, `strategic_memory_service`, `memory_embedding_service`, etc.); none import `core.rag`.
- `core/rag.py:top_k()` has graceful empty-list fallback when the corpus is missing, so an empty `.rag/` directory cannot raise.

### `.rag/` producer

- [`build_docs_index.py`](../../core/management/commands/build_docs_index.py) was inspected (1126 lines) and writes **only** `docs/INDEX.md` and `docs/_index.json`. It does **not** produce `.rag/corpus.jsonl` or `.rag/embedding_refs.txt`.
- No other management command, script, or service in the repo writes to `.rag/`.
- File timestamps confirm separate provenance: `corpus.jsonl` 2026-04-20, `embedding_refs.txt` 2025-11-02.
- **Verdict: `.rag/` is currently orphaned.** No in-repo regen path. Likely produced by an external tool that no longer ships in-tree.

### Decision queued for next session

When `.rag/` cleanup resumes, choose between:

- **Option A** — Untrack `.rag/` (`git rm --cached`, add to `.gitignore`). Production unaffected. Local Ollama tools (`askdocs`, `ask_with_docs`) silently degrade to "no context" — graceful per `top_k`'s existing fallback. ~6.5 MB removed from clone size.
- **Option B** — Write a `build_rag_corpus` management command that walks `docs/_index.json` (already produced by `build_docs_index`) and emits `corpus.jsonl` in the shape `core/rag.py` reads. Then untrack as in A. ~50 LOC.
- **Option C** — Defer indefinitely. Status quo.

No urgency: the file is committed but harmless. Mobile already excludes it via `.easignore:63`.
