## 🏆 Golden Paths - Official Flows

### Golden Path #1: Strategic Decision Loop
**Tagline:** "AI-Human Co-Leadership: Collaborative Decision-Making with Outcome Tracking"

**Entry Point:** Donkey Cockpit → Strategic Co-Leadership Card → "Start Boardroom Meeting"

**Value Proposition:** Show how AI and humans work as **equals** for strategic decisions, with full accountability and learning.

**Demo Duration:** 4-6 minutes

**Flow:**
```
1. Donkey Cockpit
   ↓ Tap "Start Boardroom Meeting"
2. BoardroomFormScreen
   → Enter topic: "Q1 2026 AI Feature Roadmap"
   → Submit
3. Leadership Cockpit / DecisionsListScreen
   → AI agents (CTO, COO, PM) provide recommendations
4. DecisionDetailScreen
   → Review 3 agent perspectives (support/concern/alternative)
   → See confidence levels, risk analysis, alternatives
5. DecisionCommitScreen
   → Commit decision: "MVP-first approach"
   → Enter justification
6. DecisionDetailScreen (later)
   → Log outcome: "Success!"
   → View metrics and attribution
7. LeadershipDashboard
   → View updated stats
   → See "I told you so" reflection (if enabled)
```

**Data Created:**
- 1 CoLeadershipDecision
- 3 AgentRecommendations (CTO: support, COO: concern, PM: alternative)
- 1 HumanDecision (override: chose PM's alternative)
- 1 DecisionOutcome (success: human was more correct)

**Demo Highlights:**
- "Each AI executive brings domain expertise - just like a real boardroom"
- "The human is ALWAYS the final decision-maker"
- "The platform tracks who was right - AI or human - to build mutual trust"

### Golden Path #2: Idea to Publish-Ready Assets
**Tagline:** "One-Tap Creative Workflows: From Concept to Professional Content"

**Entry Point:** Donkey Cockpit → Creative Pipelines Card → "Idea → Images" or "View All Pipelines"

**Value Proposition:** Show how the platform **automates complex multi-step workflows** in seconds.

**Demo Duration:** 2-4 minutes (including 45-60 seconds of actual pipeline execution)

**Flow:**
```
1. Donkey Cockpit
   ↓ Tap "Idea → Images" shortcut OR "View All Pipelines"
2. PipelinesScreen (Templates tab)
   → View "Idea to Image Set" template (3 steps)
   → Tap to launch
3. LaunchPipelineDialog
   → Enter idea: "A futuristic co-working space..."
   → Set num_images: 3
   → Tap "Launch Pipeline"
4. PipelineRunDetailScreen
   → Watch live progress (polling every 3 seconds)
   → Status: pending → running → completed
   → Current Step: 1/3 → 2/3 → 3/3
   → Progress Bar: 0% → 33% → 66% → 100%
5. Outputs Card
   → View 3 generated images in grid
   → Review expanded prompts
6. Execution Log
   → Read timestamped pipeline execution log
7. PipelinesScreen (Recent Runs tab)
   → See completed run with ✅ and 100% progress
```

**Data Created:**
- 1 CreativePipelineRun (with status, log, outputs)
- 3 AI-generated images (in ImageHistory)
- 3 detailed prompts (GPT-4o expanded)
- 1 AISession record

**Demo Highlights:**
- "Notice how fast that was? Pipeline starts immediately, runs in background"
- "Behind the scenes: GPT-4o for creative expansion, Stability AI for images"
- "In 45 seconds, idea → 3 professional images. Normally takes 30+ minutes manually"
