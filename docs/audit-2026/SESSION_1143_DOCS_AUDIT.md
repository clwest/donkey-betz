# Session 1143 — Deep Audit of `/docs/`

> **Headline:** `/docs/` holds **2,021 markdown files across 28 MB**, organized as **92 loose top-level files + 43 subdirs**. Session 1142 closed all numeric drift, but the **organizational debt** has never been audited end-to-end. This doc is that audit. It identifies what's canonical, what's stale, what's duplicated, what's empty, and what's next. No file moves have happened yet — those are in §6.

## TL;DR

**3 pathologies confirmed by Rigby's prior corpus interactions:**
1. **Stats drift across files** (e.g. agent/spider counts repeated in many places) — Session 1142 closed the loose `*_AUDIT.md` autogens; remaining drift is in handoff history + body-system snapshots.
2. **Redundant "ops/how-it-works" narratives** spread across handoffs + architecture + reports.
3. **Unstable session/PR backlinks** — files move and dead pointers result. Session 1143 locked the [DOC_LIFECYCLE.md](../00-START-HERE/DOC_LIFECYCLE.md) pointer headers to prevent this going forward.

**6 new pathologies surfaced by this audit:**
4. **Three audit dirs** (`audit/` 5 files, `audits/` 71 files, `audit-2026/` 14 files) — no clear differentiation, ripe for consolidation.
5. **Two roadmap dirs** (`roadmap/` 9 files, `roadmaps/` 2 files) — clear merge target.
6. **Empty `ops/` dir** (0 .md files).
7. **Twelve single-file or near-empty subdirs** (governance, missions, case-studies, discord, mobile, operations, verification, context-packets, decisions, integrations, workflows, canon, BUGS, tools, designs<5).
8. **Frozen Cat-B subdirs** (Jan-Feb 2026 only, never touched since): `agents/` `apis/` `body/` `features/` `guides/` `pre-launch/` `roadmap*/` `workflows/` `BUGS/` `canon/` `integrations/`.
9. **Autogen-vs-hand-edited ambiguity** (Rigby callout): some root docs are regenerated by mgmt commands (DOC-AUTOGEN header) and silently overwrite human edits; others LOOK canonical but quietly drift. `DOC_LIFECYCLE.md` formalizes the DOC-AUTOGEN header — but the audit-side action is **inventory every regen command, confirm its target file carries the autogen marker, and add a CI guardrail that fails commits which hand-edit autogen-tagged files.**

**Outcome:** master action queue in §6, gated on Chris's approval before any file moves. The DOC_LIFECYCLE.md spec and root-stability rule (Rigby's lock) are landed in this same PR — those are the methodology lock that unblocks future cleanup work.

## 1. Scope + methodology

- **Approach (locked with Rigby):** (A) top-down by subdir + (C) query-driven spot checks for duplicates.
- **Constraint:** NEVER delete docs (Chris's white-paper-corpus preservation rule from memory). Cull = move to `docs/archive/` + stub + V2 pointer header at old path.
- **Source of truth for "what exists":** `find docs/ -name "*.md"` + per-subdir `stat` for mtimes. Inbound-reference checks via `grep -rn`.
- **Tooling assumed:** `python manage.py build_docs_index` (auto-regen), `python manage.py verify_doc_claims --only-drift` (numeric drift detector), `search_docs` PA tool (chunked corpus search), `kb_tool` (852 docs / 14,149 chunks embedded).

## 4. `docs/handoffs/` retention proposal (725 files, 7.1 MB)

Handoffs span from earliest commit (2025-10-02) to today. Numbering gap doc exists at `docs/HANDOFF_NUMBERING_GAPS.md`.

**Observation:** handoffs are append-only and Rigby cites them frequently via `search_docs`. They are not redundancy noise; they are the build history. **Do not archive recent handoffs.**

**Proposal (for Chris/Rigby to ratify):**
- **Keep in `docs/handoffs/` (no move):** all Session ≥800 handoffs (i.e. last ~6 months).
- **Move to `docs/archive/handoffs-pre-800/`:** Session <800 handoffs, with V2 stub at the old path forwarding to the archive location.
- **Estimate:** of 725 handoffs, ~350 are Session <800. Disk savings minor (~3MB). Real benefit: `docs/handoffs/` becomes scannable.
- **Counter-argument:** Rigby's `search_docs` indexes via path; moving may break recently-built RAG citations. **Re-index after any move.**

**Defer ratification to Chris.** No-action default = keep everything in place. Rigby flagged this as **low-priority relative to root-level cleanup**.

**Citation-identity caveat (Rigby callout, important):** the V2 stub-redirect pattern prevents 404s on links, but it does **not** preserve `[docs/path#chunk_id]` citation identity in previously-generated RAG outputs. Any historical citation Rigby (or external white-paper material) produced against an old handoff path will resolve to the stub, not the canonical chunk. If citation stability matters more than `docs/handoffs/` cleanliness, skip this phase entirely. Chris-driven decision only.
