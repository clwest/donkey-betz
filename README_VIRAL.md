## 🚀 **Try It Yourself**

### **Quick Deploy (5 minutes)**
```bash
# Clone and deploy
git clone https://github.com/yourusername/ai-agent-learning-platform.git
cd ai-agent-learning-platform

# Deploy to Railway
railway login
railway init
railway up

# Your agents will be learning at: https://[your-project].railway.app
```

### **Local Development**
```bash
# Install dependencies
pip install -r requirements-minimal.txt

# Start Redis
redis-server

# Run the platform
python manage.py runserver 8001

# Watch agents learn at: http://localhost:8001/unified_learning_dashboard.html
```
