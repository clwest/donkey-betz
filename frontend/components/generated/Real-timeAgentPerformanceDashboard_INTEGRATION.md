
## Integration Instructions

1. Install dependencies (if needed):
   ```bash
   npm install recharts socket.io-client
   ```

2. Import the component:
   ```jsx
   import { Real-timeAgentPerformanceDashboard } from './frontend/components/generated/Real-timeAgentPerformanceDashboard';
   ```

3. Use in your app:
   ```jsx
   <Real-timeAgentPerformanceDashboard />
   ```

4. Ensure WebSocket server is running on ws://localhost:8000/ws/agent-monitor/
